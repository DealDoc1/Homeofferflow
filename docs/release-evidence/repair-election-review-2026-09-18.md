# Property-condition election and review — September 18, 2026

## Defect and implementation

Changing from repairs to As Is left `repairsText` in the collected offer.
The production renderer then treated any nonempty repair text as a repairs
election, even when the offer explicitly selected As Is. This could make
Paragraph 7D(2) disagree with the user's current interview answer.

- Collect repair text only while the repairs choice is active. Keep the typed
  browser field available if the user intentionally switches back.
- Honor an explicit As Is value before considering legacy repair text in both
  the production renderer and its staging mirror.
- Preserve existing repairs aliases and text-only legacy drafts.
- Show the entire active repair requirement in the offer review, escaped as
  text and with line breaks preserved. No review-level shortening.
- Allow long review values to wrap; no source PDF or signature coordinates changed.
