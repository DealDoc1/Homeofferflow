# TXR-1506 General Information and Notice to Consumers - Draft Foundation

## Scope of this release

This release creates only a private, source-gated draft intake for the Texas
REALTORS(R) General Information and Notice to Consumers (TXR-1506, revision
06-15-26 reviewed locally). It does not create a PDF, place initials or
signatures, send a notice, or expose a member source PDF.

This notice does not create representation. It is separate from buyer/tenant
representation agreements and must never be appended to an offer packet by
default.

## Draft intake

| Form area | Intake data | Guardrail |
| --- | --- | --- |
| Consumer | One or two consumer names | Never infer representation from the recipient role. |
| Recipient role | Buyer, tenant, seller, landlord, or other | Required only to help the agent organize the private draft. |
| Other notice | Optional agent-entered text for the source's Other area | Never generate or suggest this text. |
| Acknowledgement | Agent confirms the consumer will review and acknowledge the notice | Required before saving a private draft. |
| Broker information | Broker firm and authorized associate fields | Final values must come from the brokerage profile, not a browser field. |

## Signing and release gate

Before this becomes a completed or sent acknowledgement, HomeOfferFlow must
have an approved private source, a six-page field map including every consumer
initial/date and final-page signature/date, an authorized signer plan, and
rendered completed SignWell QA for every applicable printed field.

Until those gates pass, this workflow remains a private draft record only.
