# HomeOfferFlow Partner Marketplace Agreement

This file records the approved production agreement template rendered by
`api/admin-dashboard.py` for an eligible paid Partner's SignWell request.
The signed PDF is personalized with the Partner, representative, category,
market, and selected tier.
